AI検索について

仕組み

AI検索は、Google の Gemini API を使って質問の「意図」を解析し、ローカルにキャッシュされたイベント・メンバー・実験データの中から最適な結果を返します。

質問の意図を解析する段階で AI に送るのは質問文だけです。メンバー名簿などのデータ検索は、すべてブラウザ内で行われます。

「〜を要約して」のように文章の生成を頼んだときだけ、対象の実験・イベントの内容（実験名、場所、対象、備考、当日運営、良かった点・反省点などの自由記述）もサーバー経由で AI に送られます。担当者名やメンバー情報は送りませんが、自由記述の中に名前が書かれていればそのまま含まれます。

安全性

  • 質問文（要約を頼んだときは、対象の実験・イベントの本文も）がサーバー（Cloudflare Workers）経由で Gemini API に送信されます
  • メンバーの名簿・連絡先などのメンバー情報は AI に送信されず、ブラウザ内で処理されます
  • API キーはサーバー側で管理され、クライアントには公開されません
  • 1日あたりの使用回数に上限があり、不正利用を防止しています

API について

Google Gemini API の無料枠を使用しています。1日あたりの上限に達すると、自動的にキーワード検索に切り替わります。サーバー側の1日の上限は日本時間の0時にリセットされます（Google 側の無料枠の上限に達した場合は、日本時間17時頃にリセットされます）。

使い方のヒント

  • Enter で送信、Shift + Enter または Option(Alt) + Enter で改行
  • 最初に表示される「例」をタップすると、そのまま質問できます
  • 回答のコピーは、メッセージ横の「コピー」ボタンで可能です
  • AI が使えない場合は自動でキーワード検索に切り替わります
  • 入力は2000文字まで、検索結果の一覧は先頭50件まで表示されます
