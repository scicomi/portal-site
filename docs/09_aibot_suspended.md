# 09 AI検索(Bot)の削除と、Gemini の扱い

## 現状(2026-10-18 に更新)

**振り返りの要約は、2026-10-18 に本番で動き始めた**(`GEMINI_ENABLED = "true"`)。止め方と注意は `README.md` の「振り返りのまとめ（AI）」と `人への引き継ぎ.md` §9-7。

AI検索(`bot.html` / `bot.js` / Worker の `botPrompt.js`、`gemini.js` の意図解析と文章生成の入口)は **削除した**。コードは git の履歴にある(`git log -- bot.js`)。

削除した理由:

- 無料枠は、送った入力が Google の学習・改善に使われ得る。質問文に人名が入る(例「田中さんの参加イベント」)ほか、要約では備考・振り返りの自由記述も送るため、個人情報を無料枠に流さないことを優先して止めていた
- 再開前に直すべき不具合が 12 件あった(下の「当時の監査」)。そのうち Bot の検索の不具合(3〜8)は、Bot ごと不要になった
- 「振り返りの要約」([13](13_reflection_summary_plan.md))が、要約の役目を引き継ぐ

残したもの(振り返りの要約が使う):

- `worker/src/gemini.js`: Gemini の呼び出しの共通部分(再試行・モデルの自動検出・429 の解析・日次の使用量)。整理の内容は [14](14_reflection_summary_roadmap.md) の §3
- `worker/src/cache.js`: 一時キャッシュ(`kv_cache`)の補助
- `gemini_usage` テーブル、保存済みの API キー(`secrets` テーブル)、設定ページの Gemini 欄
- `worker/wrangler.toml` の `GEMINI_ENABLED = "false"`: **全体の非常停止**。`geminiInvoke` の先頭で見るので、画面からでも定期実行からでも、`"true"` 以外なら Gemini へ送らない

## 無料枠についての方針(13 で決定)

無料枠のみを使い、運用で問題が出ても有料枠へは切り替えない(問題が出たら機能を止める)。個人名は「書かない」注意喚起と、送る前の氏名の置換で減らす(完全には防げない)。

## 当時の監査(2026-10 の再開前の課題)と、その後

| # | 内容 | 結果 |
|---|---|---|
| 1 | 要約で備考・振り返りの自由記述が丸ごと送られる | **直した**。振り返りの本文と種類だけを、氏名・連絡先を置換して送る(Phase 2〜3) |
| 2 | `geminiGenerate` が任意の文章を送れる入口 | **削除した** |
| 3〜8 | Bot の検索ロジックの不具合 | **Bot ごと削除した** |
| 9 | `fetch` にタイムアウトが無い／例外時に予約が戻らない | **直した**(タイムアウト 20 秒、`try/finally` で必ず返す) |
| 10 | 毎分制限がトークン単位／日次を 1 人で使い切れる | 呼び出し元を `user` / `cron` に分けた。自動更新は 1 日 20 件、画面のボタンは 1 件 1 日 1 回(Phase 3) |
| 11 | API キーが URL のクエリにある | **直した**(`x-goog-api-key` ヘッダー) |
| 12 | テストが薄い | **直した**。単体(`reflection.test.mjs`)と偽の Gemini の結合テスト(`summary-api.test.mjs`)を足した |

## 補足

- 保存済みの API キーは、Google AI Studio 側で無効化しておくと安全(使うときに入れ直す)
- 旧 GAS(`gas/`)は削除済み。必要なら git の履歴から取り出せる
